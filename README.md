# RAG_AI_Assistant

# Enterprise RAG AI Assistant 🚀

A production-ready RAG application built using Streamlit, FastAPI, LangChain, Google Gemini 2.5 Flash, and FAISS.

## How to Run

1. Clone repository & set up `.env` with your `GOOGLE_API_KEY`.
2. Install dependencies: `pip install -r requirements.txt`
3. Launch Streamlit UI: `streamlit run app.py`
4. Launch FastAPI Server: `python api.py`
